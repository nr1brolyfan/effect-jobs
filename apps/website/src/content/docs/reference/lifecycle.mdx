These are backend and application integration contracts. Handlers receive payload and metadata, never lease tokens or finalization authority. Database time and exact ownership fencing remain backend responsibilities. OutcomeUnknown is an attempt outcome, not a durable state.

Names, symbol kinds and descriptions below are extracted from current public exports, including re-exports. Complete types remain in the package declarations; these tables do not maintain a second declaration set. See [checked examples](/docs/reference/examples/) for composition.

## JobLifecycle

| Export                    | Kind         | Contract                                                                                                                                                                                                                                               |
| ------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| `attemptNumber`           | value        | One-based attemptsMade + 1; may repeat after unknown outcomes and recovery. Not an invocation count or external idempotency key.                                                                                                                       |

| `cleanupEligible`         | value        | Pure terminal-retention eligibility at expiry &lt;= dbNow. Pending, Active, RetryScheduled, Isolated and Cancelled are excluded. Application/backend must coordinate domain references and deletion atomically; this result is not deletion authority. |
| `Counter`                 | value        | Nonnegative safe integer Schema for durable counters, not a policy limit.                                                                                                                                                                              |

| `JobLifecycleError`       | value + type | Bounded validation, arithmetic, eligibility or ownership failure for a pure plan.                                                                                                                                                                      |
| `JobOwnership`            | value + type | Decoded value of the JobOwnership Schema. Exact job/token/expiry/version fencing identity; handlers do not receive it.                                                                                                                                 |
| `JobSnapshot`             | value + type | Decoded complete lifecycle metadata; does not include or validate the payload. Complete durable metadata. Payload validation belongs to the codec, not this Schema.                                                                                    |
| `JobState`                | value        | Durable states; OutcomeUnknown is an attempt outcome rather than a state.                                                                                                                                                                              |
| `LeaseToken`              | value        | Bounded lease token Schema: 1–128 hexadecimal/hyphen characters.                                                                                                                                                                                       |
| `ownershipOf`             | value        | Extracts fencing identity from an Active snapshot; otherwise returns ownership-lost.                                                                                                                                                                   |

| `retryNow`                | value        | Strictly accelerates a future stored retry without changing any budget or policy.                                                                                                                                                                      |
