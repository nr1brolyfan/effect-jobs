## encrypted

Bind a decoded domain Schema to an app-owned encrypted JSON envelope. Domain encoding/validation precedes seal; open precedes domain decoding/validation. Supports independent fields, structs, arrays, optionals and unions. Job setup requires equal encryption coverage across branches of any enclosing union. Setup is lazy and fails with InvalidEncryptedSchema in the Effect error channel. Each execution snapshots schema, envelope and codec methods into a fresh Schema. Encrypted-within-encrypted and recursive domain schemas fail during setup. All encrypted fields are opened before the handler; this is not selective access. Malformed envelopes/domain data follow the existing bounded artifact decode path. Defects and interruption are not converted to codec failures. No remote key retry contract is added; configured keys must be validated before worker startup.

```ts title="Type declaration"
export declare const encrypted: <
  S extends Schema.Top,
  Envelope extends Schema.Codec<unknown>,
  RE,
  RD
>(options: {
  readonly schema: S
  readonly codec: EncryptionCodec<S["Encoded"], Envelope, RE, RD>
}) => Effect.Effect<
  Schema.Codec<
    S["Type"],
    Envelope["Encoded"],
    S["DecodingServices"] | RD,
    S["EncodingServices"] | RE
  >,
  InvalidEncryptedSchema
>
```

## EncryptionCodec

Application codec over the domain's encoded representation. The envelope must be an identity JSON schema with an own fingerprint field. Seal/open resolve application services lazily; keys are validated by application Layers at startup. Fingerprints must use stable keyed semantics independent of encryption randomness. No cryptographic implementation or authenticated context binding is supplied.

```ts title="Type declaration"
export interface EncryptionCodec<
  Encoded,
  Envelope extends Schema.Codec<unknown>,
  RE = never,
  RD = never
> {
  readonly envelope: Envelope
  readonly seal: (
    value: Encoded
  ) => Effect.Effect<Envelope["Type"], JobEncryptionError, RE>
  readonly open: (
    value: Envelope["Type"]
  ) => Effect.Effect<Encoded, JobEncryptionError, RD>
}
```

## protected

Marks an application-owned, already-protected JSON representation. Requires an own fingerprint in the encoded value. This neither proves protection nor seals or opens data. Encryption and stable fingerprint keys remain application-owned. The schema may describe any JSON fingerprint; no envelope shape or crypto key manager is imposed. Unsupported protected mappings fail when the codec runs.

Exported as `protected`; declared as `protectedPayload`.

```ts title="Type declaration"
declare const protectedPayload: <S extends Schema.Top>(schema: S) => S["Rebuild"]
```
