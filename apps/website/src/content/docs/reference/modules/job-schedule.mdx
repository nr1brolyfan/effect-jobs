## Observation

The earliest supported availability in a bounded queue head and earliest active lease. Null availability with saturated=true is inconclusive, not an empty queue. Subtract observedAt from timestamps for delays; never treat process time as DB time. Runtime observation contract. Past timestamps are due; no lifecycle state is changed.

```ts title="Type declaration"
export type Observation = typeof Observation.Type

export declare const Observation: Schema.Struct<{
  readonly observedAt: Schema.Int
  readonly nextAvailableAt: Schema.NullOr<Schema.Int>
  readonly nextRecoveryAt: Schema.NullOr<Schema.Int>
  readonly saturated: Schema.Boolean
}>
```

## observe

Observe one group's contracts or the worker's JobApi catalog in one queue. This read requires no handlers and accepts at most 500 catalog identities, independently of the metadata sample limit. Recovery is queue-scoped, including expired leases for other contracts, just like drain. Hints can become stale immediately after reading. Keep a finite repair wakeup even when timestamps are null; saturated samples especially cannot establish emptiness. The application owns authorization, activation expiry and exclusive alarm ownership.

```ts title="Type declaration"
export declare const observe: <Name extends string, D extends Definitions>(
  selection: JobGroup<Name, D> | JobApi<string, Groups>,
  queue: JobQueue,
  options?: Options
) => Effect.Effect<
  {
    readonly observedAt: number
    readonly nextAvailableAt: number | null
    readonly nextRecoveryAt: number | null
    readonly saturated: boolean
  },
  JobScheduleProtocolError | JobScheduleUnavailable,
  JobSchedule
>
```

## Reader

Qualified read-only source. Validate requests before queries, snapshot their selection, return only bounded metadata from one authoritative-clock observation, and never lock, claim, recover or modify jobs. Source acquisition/query/release must be finitely bounded. Saturation reports an incomplete pending/retry sample, not an exact queue count.

```ts title="Type declaration"
export interface Reader<E = never, R = never> {
  readonly read: (
    request: Request
  ) => Effect.Effect<Observation, E | JobScheduleProtocolError, R>
}
```
