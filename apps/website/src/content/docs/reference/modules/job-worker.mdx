## drain

Runs bounded recovery and claims with concurrency fixed at worker construction. Idle observes an empty claim; MoreWork reaches the run limit; Backoff requests delayed retry after storage uncertainty. None promises exactly-once effects.

```ts title="Type declaration"
export declare const drain: (
  queue: import("./JobQueue.js").JobQueue<string>,
  limits?: GroupWorker.DrainLimits | undefined
) => import("effect/Effect").Effect<
  | {
      readonly _tag: "Backoff"
      readonly phase: "claim" | "recovery" | "reconciliation"
      readonly claimed: number
      readonly reason?: "JobPolicyIncompatible"
    }
  | {
      readonly _tag: "Idle"
      readonly claimed: number
      readonly recovered: number
    }
  | {
      readonly _tag: "MoreWork"
      readonly claimed: number
      readonly recovered: number
    },
  | import("./internal/worker/Capability.js").JobWorkerConfigurationError
  | import("./internal/worker/Capability.js").JobWorkerNotReady,
  JobWorker
>
```

## layer

Requires installed handlers for every group in the supplied JobApi. Construction is inert; drain and polling have explicit application-owned lifetimes.
