## JobsTransaction

Transaction callback capability; never fabricate or retain it outside the callback. E and R preserve storage errors and requirements. No public constructor, SQL, commit, rollback or replay authority; sequence operations on the same transaction.

```ts title="Type declaration"
export interface JobsTransaction<E = never, R = never> {
  readonly [JobsTransactionTypeId]: {
    readonly assertActive: Effect.Effect<void, JobsTransactionClosed>
    readonly insertOrCompare: (
      prepared: PreparedJob
    ) => Effect.Effect<
      EnqueueResult,
      E | JobIntegrityConflict | JobPolicyIncompatible | JobsTransactionClosed,
      R
    >
  }
}
```

## JobTransactionsService

Qualified application manager port, delegating join-or-establish without a second transaction engine. The outer application owner controls commit and replay.

```ts title="Type declaration"
export interface JobTransactionsService<ManagerError, ManagerRequirements = never> {
  readonly withTransaction: <A, E, R>(
    body: (jobsTx: JobsTransaction<ManagerError>) => Effect.Effect<A, E, R>

}
```
