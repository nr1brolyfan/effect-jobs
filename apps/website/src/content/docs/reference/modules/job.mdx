## InvalidJobDefinition

Invalid static declaration. Schema issues include a stable reason and a bounded declaration path. The root path is empty and array elements use index 0. Control characters are escaped and long diagnostic paths end in an ellipsis.

## make

Lazily declares a frozen contract with version 1 when omitted. Each execution snapshots the configuration.
