## make

Declares a named group, preserving aliases and payload types. The name is a compile-time service identity, not a durable job identity. Each construction allocates a distinct Context key, even for identical names and definitions. Reuse the same group reference when installing handlers and building a worker.

```ts title="Type declaration"
export declare const make: <const Name extends string, const D extends Definitions>(
  name: Name,
  definitions: D
) => Effect.Effect<JobGroup<Name, D>, InvalidJobGroup>
```
