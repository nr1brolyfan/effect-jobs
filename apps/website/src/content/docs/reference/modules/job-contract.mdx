## EncodedJobPayload

Validated canonical payload and semantic bytes. Codec executions own their buffers; receivers copy before retention because readonly does not freeze Uint8Array contents.

## EnqueueInput

Decoded payload, stable producer identity and resolved policy. No caller job ID. Matching duplicates retain the original queue, policy and availability.

```ts title="Type declaration"
export interface EnqueueInput<Payload> {
  readonly producer: ProducerIdentity
  readonly payload: Payload
  readonly policy: JobPolicy
  /** Omitted means database time on first insertion, never on matching duplicate. */
  readonly availableAt?: DateTime.Utc
}
```

## HandlerContext

Handler metadata without SQL, lease tokens or finalization authority. nextFinalizationNumber is one-based and may repeat after unknown outcomes and recovery.

```ts title="Type declaration"
export interface HandlerContext {
  readonly jobId: JobId
  readonly catalog: JobAddress
  readonly producer: ProducerIdentity
  /** finalizedAttempts + 1; may repeat after unknown outcomes and stalled recovery. */
  readonly nextFinalizationNumber: number
}
```
