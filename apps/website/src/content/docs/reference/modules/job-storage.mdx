## make

Captures provider requirements once and snapshots the budget. Typed provider failures cross a safe infrastructure boundary; library protocol/admission errors, defects, interruptions and explicit Unknown results retain their semantics. Own the source's lifetime outside this service; no borrowing, readiness, DDL, polling, cleanup or pool shutdown occurs here. This is not an atomicity proof.
