## layer

Starts one scoped loop per queue when the Layer is built, requiring JobWorker. Validates all queues before forking. Scope closure first interrupts admission loops, including permit waits, recovery and in-flight claims. Already-started executions retain their scopes and can finalize during one shared grace period. After grace expiry remaining executions are interrupted, never released as safe unexecuted work. Unknown effects remain subject to lease recovery. Source acquisition/control/release and handler finalizers must be finitely bounded and interruption-cooperative; a grace timer cannot hard-kill arbitrary native or uninterruptible user code. One-shot drain interruption remains immediate. Build only in the application-owned lifetime; importing or constructing starts no work.

```ts title="Type declaration"
export declare const layer: (
  queues: ReadonlyArray<JobQueue>,
  options?: Options
) => Layer.Layer<never, JobWorkerConfigurationError | JobWorkerNotReady, JobWorker>
```

## Options

Polling configuration. idlePoll defaults to one second and must be positive. Idle/backoff sleeps include jitter. shutdownGrace defaults to 30 seconds and accepts zero through five minutes. Each option uses whole milliseconds. recoveryRetryInterval accepts a positive, bounded Duration and defaults to Duration.seconds(30). It enables recovery on the next eligible round during claim backoff.

```ts title="Type declaration"
export interface Options extends DrainLimits {
  readonly recoveryRetryInterval?: Duration.Duration
  readonly idlePoll?: Duration.Duration
  readonly shutdownGrace?: Duration.Duration
}
```
