## cleanupEligible

Pure terminal-retention eligibility at expiry &lt;= dbNow. Pending, Active, RetryScheduled, Isolated and Cancelled are excluded. Application/persistence must coordinate domain references and deletion atomically; this result is not deletion authority.

## finalize

Plans one fenced Complete/Retry/Dead/Isolate transition and increments attempts once. Uses the first stored retry policy; next availability &gt;= retryBefore or exhausted attempts becomes Dead. retryBefore limits retry scheduling, not handler execution.

```ts title="Type declaration"
export declare const finalize: (
  input: unknown,
  expected: JobOwnership,
  command: JobFinalization,
  dbNow: number
) => Result.Result<JobSnapshot, JobLifecycleError>
```
