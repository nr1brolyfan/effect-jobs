Declare logical queues and versioned payloads, then identify each business consequence. Constructors do not create storage or start workers. The root entrypoint intentionally exports nothing; use the focused subpaths below.

Names, symbol kinds and descriptions below are extracted from current public exports, including re-exports. Complete types remain in the package declarations; these tables do not maintain a second declaration set. See [checked examples](/docs/reference/examples/) for composition.
