Install every catalog group before constructing a worker. A finite drain and a scoped polling Layer are separate operations. Local permits bound claims for one worker; they do not provide global concurrency or exactly-once external delivery.

Names, symbol kinds and descriptions below are extracted from current public exports, including re-exports. Complete types remain in the package declarations; these tables do not maintain a second declaration set. See [checked examples](/docs/reference/examples/) for composition.

## JobPolling

Import: `effect-jobs/JobPolling`. Source: `src/JobPolling.ts`.

| Export    | Kind  | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `layer`   | value | Starts one scoped loop per queue when the Layer is built, requiring JobWorker. Validates all queues before forking. Scope closure first interrupts admission loops, including permit waits, recovery and in-flight claims. Already-started executions retain their scopes and can finalize during one shared grace period. After grace expiry remaining executions are interrupted, never released as safe unexecuted work. Unknown effects remain subject to lease recovery. Source acquisition/control/release and handler finalizers must be finitely bounded and interruption-cooperative; a grace timer cannot hard-kill arbitrary native or uninterruptible user code. One-shot drain interruption remains immediate. Build only in the application-owned lifetime; importing or constructing starts no work. |
| `Options` | type  | Polling configuration; idlePollMillis defaults to 1,000 positive integer milliseconds. Idle/backoff sleeps include jitter. shutdownGraceMillis defaults to 30,000; integer 0–300,000, with zero requesting immediate interruption.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
