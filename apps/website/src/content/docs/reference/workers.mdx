Install every catalog group before constructing a worker. A finite drain and a scoped polling Layer are separate operations. Local permits bound claims for one worker; they do not provide global concurrency or exactly-once external delivery.

Open a module or symbol to see its TypeScript declaration. See [checked examples](/docs/reference/examples) for composition.

## JobPolling

[`effect-jobs/JobPolling` signatures](/docs/reference/modules/job-polling)

| Export                                                   | Kind  | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`layer`](/docs/reference/modules/job-polling#layer)     | value | Starts one scoped loop per queue when the Layer is built, requiring JobWorker. Validates all queues before forking. Scope closure first interrupts admission loops, including permit waits, recovery and in-flight claims. Already-started executions retain their scopes and can finalize during one shared grace period. After grace expiry remaining executions are interrupted, never released as safe unexecuted work. Unknown effects remain subject to lease recovery. Source acquisition/control/release and handler finalizers must be finitely bounded and interruption-cooperative; a grace timer cannot hard-kill arbitrary native or uninterruptible user code. One-shot drain interruption remains immediate. Build only in the application-owned lifetime; importing or constructing starts no work. |
| [`Options`](/docs/reference/modules/job-polling#options) | type  | Polling configuration. idlePoll defaults to one second and must be positive. Idle/backoff sleeps include jitter. shutdownGrace defaults to 30 seconds and accepts zero through five minutes. Each option uses whole milliseconds. recoveryRetryInterval accepts a positive, bounded Duration and defaults to Duration.seconds(30). It enables recovery on the next eligible round during claim backoff.                                                                                                                                                                                                                                                                                                                                                                                                             |
