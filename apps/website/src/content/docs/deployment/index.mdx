Start with where your **application data** already lives. To commit a domain write and a job together, the two writes must use the same transaction. Then choose what wakes the worker.

  <LinkCard

For Cloudflare, use **PostgreSQL + Hyperdrive** if the domain write is already in PostgreSQL. Choose **DO SQLite** when the same object owns the domain write and the jobs; a single SQLite object doesn't give you a transaction across objects or stores.

The job definitions, handlers and retry policy can stay the same. The store binding, transaction boundary and wake strategy change. If you haven't built a producer and handler yet, follow [Your first job](/docs#your-first-job) first.
